## Useful commands

* `npm run build` - Compile TypeScript into JavaScript.
* `npm run watch` - Watch for file changes and automatically compile
* `npm run test` - Watch for file changes and automatically compile
* `npx cdk deploy` - Deploy the stack to your default AWS account/region
* `npx cdk diff` - Compare the deployed stack with the current local state
* `npx cdk synth` - Generate the synthesized CloudFormation template


## CDK commands

* `cdk init app --language typescript` - Initialize a new CDK project using TypeScript 
* `cdk bootstrap` - Set up the initial environment required for CDK applications
* `cdk synth` - Generate a CloudFormation template for each stack
* `cdk deploy` - Deploy the stacks to AWS
* `cdk list` - List available stacks (runs cdk synth in the background)
* `cdk diff` - Show the difference between the local stack and the deployed version
* `cdk doctor` - Diagnose potential issues in the CDK environment
* `cdk destroy <stack_name>` - Delete the specified stack
